How to install the wallpaper

1. Export the image

Open the online editor, choose your exact device model, adjust the image and export BMP. Use the resolution shown for your device; Xteink X3 uses 528 × 792, while X4 / X4 Pro typically use 480 × 800.

2. Copy it to the microSD card

Turn off or safely disconnect the reader, remove the microSD card and open it on your computer. For CrossPoint, create a .sleep/ folder in the card root and copy BMP files there. For one fixed wallpaper, place a supported file such as sleep.bmp in the root if your firmware supports it.

3. Select it on the reader

Reinsert the card and open the reader settings. In CrossPoint, choose Settings → Display → Sleep Screen → Custom. Menu names and supported formats vary by firmware; consult your firmware documentation if this option is missing.

Compatibility note: choose a format supported by your firmware. BMP is the recommended general-purpose choice; PXC is specific to compatible CrossPoint builds. Never use an image prepared for a different screen size.

Device support note: exported file formats do not guarantee that every device or firmware accepts every mode. Check your reader's documentation before using color modes or PXC.
