# EInkXT Wallpaper Studio

Кроссплатформенный инструмент для подготовки изображений для E-Ink-дисплеев. Настольное приложение использует Python, PySide6, Pillow и NumPy. Сайт представляет собой статический веб-сайт со встроенным редактором: изображения обрабатываются локально в браузере и не загружаются на сервер. Веб-редактор реализован отдельно; исходный генератор использовался как ориентир по взаимодействию, а не как исходная кодовая база.

- **Сайт проекта:** https://evoll.github.io/EInkXTWallpaperStudio/
- **Репозиторий:** https://github.com/evoll/EInkXTWallpaperStudio
- **Последний релиз настольного приложения:** https://github.com/evoll/EInkXTWallpaperStudio/releases/latest

## Возможности

- Профили устройств Xteink X3 и X4, пользовательские размеры, книжная и альбомная ориентация, кадрирование.
- Пресеты обработки изображений, яркость, контраст, гамма, резкость и дизеринг (по умолчанию Atkinson, также Floyd–Steinberg, Bayer, Jarvis–Judice–Ninke, Stucki, Burkes и отключение дизеринга).
- Режимы оттенков серого, приближённая к Kaleido квантизация до 4096 RGB-значений, приближение палитры Spectra 6 и подготовка полноцветных изображений.
- Экспорт в PNG, BMP и CrossPoint PXC в настольном приложении. Перед использованием проверьте совместимость с устройством и прошивкой: название цветового профиля не гарантирует, что физический экран поддерживает соответствующий формат файла.
- Пакетная обработка и сохранение настроек проекта в формате `.xtws` в настольном приложении.
- Русский и английский интерфейсы настольного приложения; дополнительные переводы загружаются из `lang/<code>.json`.
- Статический сайт на Jekyll поддерживается отдельно в ветке `site-app`; настольное приложение и workflow выпуска релизов находятся в ветке `main`.

## Запуск настольного приложения из исходного кода

В CI используется Python 3.12. Рекомендуется Python 3.12 или новее.

### Windows PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
python main.py
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
PYTHONPATH=src python main.py
```

## Тесты

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

## Локальная сборка исполняемого файла

Сначала установите зависимости, затем выполните:

```bash
pyinstaller --noconfirm --clean EInkXTWallpaperStudio.spec
```

Сборку необходимо выполнять отдельно на каждой целевой ОС. GitHub Actions не выполняет кросс-компиляцию этих настольных приложений.

## Добавление перевода

Создайте файл `lang/<код-языка>.json`. Ключи должны соответствовать исходным английским строкам интерфейса из `lang/en.json`; задайте `__language_name__` как название языка. Для отсутствующих ключей используется английский текст. При упаковке приложения каталог `lang` включается согласно настройкам PyInstaller.

## Онлайн-редактор

Веб-редактор доступен на странице [EInkXT Wallpaper Studio](https://evoll.github.io/EInkXTWallpaperStudio/editor.html) и публикуется через GitHub Pages. Он поддерживает загрузку изображений, кадрирование, размеры устройств, пресеты, дизеринг Atkinson/Floyd/Bayer/Jarvis/Stucki, оттенки серого и приближённые цветовые режимы, экспорт в PNG/BMP/PXC. Экспорт выполняется в полном выбранном разрешении и может занимать больше времени при очень больших пользовательских размерах. Веб-редактор реализован независимо; побитовое совпадение результатов с настольным движком или исходным сторонним генератором не гарантируется.

## Источник вдохновения

На компоновку и рабочий процесс редактора повлиял общедоступный [генератор обоев Xteink X3 / X4](https://xtwallgen.madebybaker.dev/).
