Installation notes

  • Download the archive or executable from the latest release.
  • On Windows, run the EXE. If SmartScreen warns about an unknown publisher, verify that the file came from the project's official Releases page.
  • On macOS, unzip the package and run the app or executable. Unsigned builds may require approval in Privacy & Security.
  • On Linux, mark the executable as executable if needed: chmod +x EInkXTWallpaperStudio.
  • For source builds, clone the repository and follow the README.

If no release exists yet, the latest-release link may show a not-found page until the first version tag is published. If a release is not available yet, wait for the first successful tagged release.
