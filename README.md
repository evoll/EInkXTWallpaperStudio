# EInkXT Wallpaper Studio — Online Editor

An online editor for preparing images for E-Ink displays: https://evoll.github.io/EInkXTWallpaperStudio/editor.html

## Features

- Load an image from your computer or drag and drop it into the editor.
- Device profiles for Xteink X3 and X4, custom dimensions, portrait and landscape orientation.
- Image framing/cropping, scaling, rotation, and centering.
- Processing presets and controls for brightness, contrast, gamma, sharpness, and noise reduction.
- Atkinson, Floyd–Steinberg, Bayer, Jarvis–Judice–Ninke, and Stucki dithering.
- Grayscale output and approximate color modes.
- Result preview, histogram, and estimated output file size.
- Export processed images as PNG, BMP, and PXC.
- Save and load project settings, and process images in batches.
- Russian and English interface.

Image processing runs locally in your browser; images are not uploaded to a server. Output is rendered at the full selected resolution, so exporting large images may take longer. The browser editor is an independent implementation of the desktop application, so byte-for-byte identical results are not guaranteed.
